# Aula 1 — Primeira API local

1. Clonar o projeto.
2. Criar e ativar `.venv`.
3. Instalar `requirements.txt`.
4. Executar `uvicorn main:app --reload`.
5. Abrir `/docs`.
6. Testar `/`, `/api/status` e `/api/clientes`.
7. Executar `app/cliente_api.py`.
8. Personalizar `/api/status`.
9. Fazer commit.

## Checkpoint

- Swagger aberto;
- resposta HTTP 200;
- JSON de `/api/status`;
- lista de clientes no terminal;
- commit criado.
